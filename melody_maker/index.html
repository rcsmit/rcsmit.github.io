How to write it
e d cNote names a–g. Each note goes to the octave closest to the note before it, so c a drops to the A below.
c'   a,' jumps an octave higher than that, , an octave lower.
c#   e_# is sharp, _ is flat (because a plain b is the note B).
c c2 c4 c8Length counted in eighth notes: none = eighth, 2 = quarter, 3 = dotted quarter, 4 = half, 8 = whole. c/2 = sixteenth.
c - - -Each - holds the previous note one eighth longer. It can also carry a note over a bar line.
z2   r2Rest (z or r), with a length in the same way.
[C] [G7] [Am]Chord, placed where it starts. It keeps sounding until the next chord, even across bars. Also: m, 7, maj7, m7, dim, aug, sus2, sus4, 6, 9, add9, slash chords like [C/E], and [N.C.] for no chord.
|Bar line. Each line of text becomes one line of notation.
Chorus x2:A line ending in : starts a section; x2 plays it twice.
% noteA line starting with % is a comment and is ignored.

Spaces don't matter, so edccc and ed cc c are the same. Bars that are too short or too long get a warning but still play at the length you wrote, so a pickup bar works.
